# dsh-retro

[English documentation](../README.md) | [简体中文文档](../README.zh-CN.md)

This directory contains the runtime source, bundled skill and shared patch. Its private package manifest keeps existing local profile links working. Install new profiles from the repository root.

本目录保存运行源码、配套技能和共享 patch。私有清单用于兼容已有本地 profile 链接，新安装统一使用仓库根目录。

```sh
dsh plugin --profile web add github:StellatoL/retro
```
